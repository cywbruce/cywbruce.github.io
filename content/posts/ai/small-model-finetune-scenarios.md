---

## 核心逻辑

| | 大模型 | 小模型微调 |
| --- | --- | --- |
| 角色 | 通才 | 专才 |
| 代价 | 贵、相对慢、偏云端 | 便宜、快、可边缘/内网 |
| 本质 | 通用能力 | **用极窄任务换效率与成本** |

任务边界清晰、模式相对固定时，小模型常能以远低成本逼近大模型在该任务上的效果。黄金法则：**任务越窄，模型可越小，往往更稳、更便宜。**

---

## 一、0.5B 级（如 Qwen2.5-0.5B、TinyLlama 等）

**画像：** 高级模式匹配器；复杂推理弱，固定输入输出上很强。

| 场景 | 为何够用 | 部署直觉 |
| --- | --- | --- |
| 电商商品属性抽取 → JSON | 字段有限，信息搬运 | 后台高 QPS，成本极低 |
| IT 工单分类 | 类别封闭、标注便宜 | 内网即可 |
| 敏感信息脱敏（NER） | 实体类型有限、模式规律 | 管道内实时、低延迟 |
| 智能家居指令解析 | 设备/动作集合有限 | 端侧芯片、可离线 |
| 日志异常分类 | 结构化强、模式可枚举 | 替代部分正则规则 |

不要让 0.5B 当通才；让它当「分类 / 抽取 / 格式转换专家」。

---

## 二、1B～3B 级（如 Qwen2.5-1.5B/3B、Phi-3-mini、Gemma-2-2B 等）

**画像：** 初步理解与简单推理，能支撑短多轮、阅读组织类任务。

| 场景 | 为何够用 | 注意 |
| --- | --- | --- |
| 企业知识库问答（RAG） | 知识在检索结果里，模型做阅读组织 | 单卡消费级可内网部署 |
| 垂直代码补全（固定技术栈） | 用司内代码微调对齐规范 | 规范性可胜过泛用大模型「随便写」 |
| 病历 / 文书结构化 | 术语与格式相对标准 | 合规：数据不出域 |
| 垂直客服多轮（退换货等） | 话术模式收敛 | 人工兜底剩余比例 |
| 游戏 NPC 短对话 | 风格可控、无需世界知识 | 可端侧 |
| 合同初审辅助 | 特定合同类型 + 标注风险点 | **仅初审**，必须人审 |

---

## 三、对比与选型

| 维度 | 0.5B 微调 | 3B 级微调 | 70B+ 通用 |
| --- | --- | --- | --- |
| 速度 | 极快 | 很快 | 相对慢 |
| 成本 | CPU/边缘也可 | 单卡消费级常见 | 多卡/云端 |
| 复杂度 | 分类/NER/转换 | RAG/简单推理/多轮 | 复杂推理与创作 |
| 隐私 | 易本地 | 易本地 | 常上云 |

```text
任务规则能否一句话说清？
  ├─ 能 → 先试 0.5B
  └─ 不能 → 需要理解但领域窄？ → 3B
            需要广知识/强推理 → 7B+ 或大模型 API
```
