「JVM 有多少知识点？」没有标准数字。更有用的是：**按领域建地图，按目标定深度**。

## 为什么数不清

1. **场景差**：只会启动参数，和会看 GC 日志、压测调停顿，深度差一个数量级。  
2. **持续演进**：虚拟线程（Loom）、新收集器、容器感知等不断加层。  
3. **交叉重叠**：内存管理与 GC、并发与内存模型绑在一起，拆开计数会重复。

### 粗估（方便规划，不是考纲）

| 目标 | 量级 |
| --- | --- |
| 入门～中级（日常开发 + 面试基础） | 约 **20** 个核心点 |
| 生产排障 / 性能向 | **50～100+** 细分项（具体参数、工具手法、案例） |

## 十大核心领域

| # | 领域 | 你要搞清什么 |
| --- | --- | --- |
| 1 | **运行时内存** | 堆 / 栈 / 元空间、直接内存；各区 OOM 长什么样 |
| 2 | **对象与分配** | 对象头、分配、逃逸分析直觉、晋升 |
| 3 | **垃圾回收** | 分代思想、常见收集器（G1/ZGC 等）、停顿与吞吐取舍 |
| 4 | **类加载** | 加载过程、双亲委派、SPI/热部署为何打破 |
| 5 | **字节码与执行** | 栈机模型、常见指令、解释执行 |
| 6 | **JIT** | C1/C2、分层编译、热点、OSR 直觉 |
| 7 | **并发与内存模型** | 与 JMM/锁/线程的交叉（面试常从此进 JVM） |
| 8 | **诊断工具** | `jstat` / `jmap` / `jstack` / `jcmd` / JFR / Arthas / MAT |
| 9 | **容量与调优** | 堆大小、GC 目标、线程与本地内存协同 |
| 10 | **部署形态** | 容器 cgroup、云上限制、与编排联动 |

安全、JNI、底层校验等可按岗加深，不必人人同等深度。

更细的 GC 入门见 [JVM GC 入门](/posts/java/jvm-gc-basics/)，横向对比见 [多语言 GC](/posts/java/gc-across-languages/)。

## 入门必会的约 20 个点（Checklist）

1. 堆 vs 栈 vs 元空间  
2. Young / Old 为何分代  
3. Minor GC / Full GC 直觉  
4. STW 是什么  
5. `OutOfMemoryError` 常见几类  
6. `StackOverflowError` 常见原因  
7. 双亲委派在防什么  
8. 类加载大致阶段  
9. `synchronized` 与对象头的一点关系（了解即可）  
10. 为什么「分配多、短命对象」偏 Young GC  
11. G1 大概是 Region + 停顿目标  
12. ZGC 适合什么诉求（低延迟大堆）  
13. `-Xms` / `-Xmx` 含义  
14. 看 GC 日志要抓停顿与频率  
15. `jstack` 看线程卡在哪  
16. `jmap`/`jcmd` 堆相关用途  
17. 直接内存 / NIO 也可能 OOM  
18. 容器里不要只抄物理机绝对值  
19. 先定位再调参，禁止盲改  
20. 调优要有前后对比指标（延迟、吞吐、GC 停顿）

## 学习路径建议

| 阶段 | 做什么 |
| --- | --- |
| 基础 | 《深入理解 Java 虚拟机》内存、GC、类加载章节；本地用 `jinfo`/`jstat` 看一眼 |
| 实战 | 对真实或 demo 服务抓一次慢请求 + 一次 GC 抖动；用 Arthas/`jstack` |
| 生产 | 读 [生产向 JVM 指南](/posts/java/jvm-production-guide/)：工具链、教训、K8s/低延迟场景 |
| 专家 | 建立自己的「故障手册」：每个案例写清现象→证据→改动→回滚 |

面试向可配合 [Java 面试题 · JVM 章节](/posts/java/java-interview/)。
