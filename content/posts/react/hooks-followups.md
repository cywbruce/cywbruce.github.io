## useState

**主问：** `useState` 的更新是同步还是异步的？批量更新了解吗？

| 级别 | 追问 | 期望 |
| --- | --- | --- |
| 初 | 为什么推荐 `setX(x => x + 1)`？ | 连续更新、闭包旧值 |
| 中 | 在 `setTimeout` / Promise 里 setState，还批量吗？（视 React 版本） | 18 自动批处理意识 |
| 高 | 能举例「必须刷新读到最新 state」的场景吗？如何做？ | flushSync 慎用、或结构调整 |

**定级：** 只知道「异步」口头禅偏初级；能讲清批处理与函数式更新 → 中级。

---

## useEffect

**主问：** 依赖数组你怎么定？漏了或写多了会怎样？

| 级别 | 追问 | 期望 |
| --- | --- | --- |
| 初 | 清理函数什么时候跑？ | 下次 effect 前 + 卸载 |
| 中 | 如何避免请求竞态？ | abort / 忽略过期 |
| 中 | props → state 的 Effect 同步为何常被劝退？ | 重复源、中间态 |
| 高 | 「Effect 编排整个业务流」如何重构？ | 事件驱动、查询库、派生 |

**定级：** 能独立讲竞态与清理 → 至少中级。

---

## useMemo / useCallback / memo

**主问：** 这两兄弟是不是写得越多越快？

| 级别 | 追问 | 期望 |
| --- | --- | --- |
| 初 | 它们缓存的是什么？ | 值 / 函数引用 |
| 中 | 什么时候 memo 完全失效？ | props 每次新引用 |
| 高 | 如何用数据证明某次 memo 有收益？ | Profiler、勿过早优化 |
| 高 | React Compiler 若开启，手写 memo 策略怎么变？ | 减少样板、懂规则仍重要 |

---

## useRef

**主问：** `useRef` 和 `useState` 怎么选？

| 级别 | 追问 | 期望 |
| --- | --- | --- |
| 初 | 改 `ref.current` 为何不渲染？ | 不在渲染数据流里 |
| 中 | 保存「最新回调」的 ref 模式解决什么？ | 订阅稳定 + 读新值 |
| 高 | ref 回调 / 清理在严格模式双调用下注意什么？ | 幂等挂载清理 |

## 自定义 Hook

**主问：** 判断下面该不该做成 Hook：本地存储同步、金额格式化、WebSocket 订阅。

| 级别 | 追问 | 期望 |
| --- | --- | --- |
| 初 | 命名必须 `use` 吗？ | 约定 + lint |
| 中 | Hook 里能否再调多个 Hook？规则是什么？ | 顶层、稳定顺序 |
| 高 | 开源一个 Hook 库，API 兼容与测试你怎么做？ | 纯逻辑抽取、SSR 安全 |

更多对比见 [Hook 与工具函数](/posts/react/hook-vs-utils/)。

## 45 分钟 Hooks 专题题单（建议）

1. 函数式更新 + 批处理（初→中）  
2. Effect 依赖与竞态（中）  
3. memo 失效现场分析（中）  
4. 自定义 Hook 设计题：`useLocalStorage`（中→高）  
5. 架构题：减少 Effect 编排（高）

候选人若在第 2、4 题表现稳定，通常可按**中级**给；第 5 题有体系答案再冲**高级**。
