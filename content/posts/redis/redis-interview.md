## 一、基础与数据结构

### 1. 为什么快？单线程还快吗？（初级）

**主问：** Redis 为什么性能高？

**参考答案：** 内存操作；I/O 多路复用；高效数据结构；命令执行路径短。主流版本命令执行仍偏单线程模型（有 I/O 线程等演进，候选人说到「执行单线程避免竞争」即可）。瓶颈常在网络、大 Key、慢命令，而非「缺多线程」。

**追问：** 哪些命令会变慢？（`KEYS`、大 `hgetall`、无游标的大集合操作）

---

### 2. 五类基础结构怎么选？（初级～中级）

**主问：** String / Hash / List / Set / ZSet 各适合什么？

**参考答案：**

| 类型 | 典型场景 |
| --- | --- |
| String | 缓存对象、计数、分布式锁 value、Session |
| Hash | 对象字段级读写、购物车 |
| List | 队列、最新动态（注意阻塞与可靠性） |
| Set | 去重、共同关注 |
| ZSet | 排行榜、延时区间 |

**追问：** 排行榜用 ZSet 如何取 TopN？同分怎么处理？Bitmap / HyperLogLog / Stream 听过吗？（加分）

**定级：** 能对号入座 → 初级；能谈编码细节（ziplist 等）→ 中。

## 二、过期、淘汰与内存

### 3. 过期策略（初级～中级）

**主问：** Key 过期后是立刻删吗？

**参考答案：** 惰性删除（访问时检查）+ 定期抽样删除。已过期可能仍占内存直到被抽到或访问到。

**追问：** 大量 Key 同时过期会怎样？如何打散 TTL？

---

### 4. 内存满了怎么办？（中级）

**主问：** `maxmemory-policy` 常见策略？

**参考答案：** `noeviction`（写报错）、`allkeys-lru`、`volatile-lru`、`allkeys-lfu` 等。缓存场景常用 LRU/LFU；要讲清「只对带 TTL 的 volatile-*」与 allkeys 差别。

**追问：** 线上如何观察内存与驱逐？如何发现大 Key？

---

## 三、缓存三大问题

### 5. 穿透、击穿、雪崩（中级必考）

**主问：** 三者区别与防治？

**参考答案：**

| 问题 | 含义 | 常见手段 |
| --- | --- | --- |
| 穿透 | 查不存在的数据打到 DB | 布隆过滤器、缓存空值、参数校验 |
| 击穿 | 热 Key 过期瞬间打爆 DB | 互斥重建、逻辑过期、永不过期+异步刷新 |
| 雪崩 | 大量 Key 同时失效或 Redis 挂 | TTL 打散、多级缓存、集群高可用、限流降级 |

**追问：** 布隆过滤器误判意味着什么？逻辑过期如何保证正确性？

**定级：** 三者分得清并各给一招 → 中级线。

---

### 6. 缓存与 DB 一致性（中高级）

**主问：** 先更新 DB 还是先更新缓存？

**参考答案：** 常见推荐：**更新 DB，删除缓存**（让下次读取重建）。避免「先改缓存再写 DB」失败导致脏数据。延迟双删、订阅 binlog 删缓存用于更高要求。接受最终一致；强一致场景评估是否适合缓存。

**追问：** 删缓存失败怎么办？读写并发旧值回写如何缓解？

---

## 四、分布式锁

### 7. 用 Redis 做锁（中级）

**主问：** `SET key value NX EX` 够不够？要注意什么？

**参考答案：** 基础：SET NX + 过期。必须：唯一 value（谁加谁解）、finally 解锁用 Lua 校验 value；考虑业务超时续期（看门狗，如 Redisson）；主从切换可能丢锁（Redlock 有争议，需讲清权衡）。锁粒度、重入、不可重入业务要说清。

**追问：**

1. 为什么不能先 GET 再 DEL？  
2. 锁过期了业务还没做完怎么办？  
3. ZooKeeper / etcd 锁对比？

**定级：** 只知道 setnx → 初级；能讲误删、续期、主从风险 → 中高。

## 五、持久化与高可用

### 8. RDB vs AOF（中级）

**主问：** 两种持久化差别？会丢数据吗？

**参考答案：** RDB 快照，恢复快，间隔内易丢；AOF 记写命令，可配置 fsync 策略，更耐丢、文件更大，有重写。可混用。fork 子进程可能引起延迟，大内存实例需关注。

**追问：** AOF 重写做什么？`everysec` 大约丢多少？

---

### 9. 哨兵与集群（中高级）

**主问：** 哨兵和 Cluster 各解决什么？

**参考答案：** 哨兵：主从监控与自动故障转移，单分片数据。Cluster：数据分片（槽），水平扩展；迁移、倾倒、跨槽事务限制要了解。

**追问：** 集群中一个节点挂了读怎么办？热 Key 集中在一个槽怎么治？

---

## 六、场景题

### 10. 热 Key / 大 Key（高）

**热 Key：** 本地缓存、拆 Key、读写分离、代理层限流。  
**大 Key：** 拆分、禁止无游标全量、`UNLINK`、监控与规范。

### 11. 计数与限流（中）

**主问：** 接口限流怎么用 Redis 做？

**参考答案：** 固定窗口 INCR+TTL、滑动窗口（ZSET）、令牌桶/漏桶（Lua 或组件）。讲清边界误差与性能。
